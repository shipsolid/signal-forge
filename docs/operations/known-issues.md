# Known issues

Recurring limitations and accepted trade-offs, consolidated from notes scattered across
[reliability.md](reliability.md), [supply-chain.md](supply-chain.md),
[testing.md](../testing.md), and [resilience-patterns.md](resilience-patterns.md) "what this
doesn't cover" sections, plus code-level findings from writing those pages. This is not an
incident log — this is a personal lab with no on-call and no incident process (see
[README.md § Ownership Boundary](../../README.md#ownership-boundary)) — it is a single place to
check before assuming a gap is new.

Planned/deferred work that's already tracked with a target is in
[README.md § Roadmap](../../README.md#roadmap) (SLO rules default-off, Pyroscope profiling,
Faro source-map upload, datastore HA operator migration) and is not duplicated here.
